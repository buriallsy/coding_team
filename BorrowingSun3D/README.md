# 借晴 · 3D 塔台灰盒

第 05D 轮补上开场引导与签收页。从西岸上塔，借雨升高、借风接岸，经两面镜子把日光送到东岸，再用原来的雨水驱动货车，把一箱水果送到花庭。3D 分支起于 `2d-baseline`（`6175db9`）。Windows 验收待跑，`3d-final` 待双平台确认。 [首玩和双平台验收](Docs/ROUND_05D.md) · [3D 关系图](Docs/RELATIONSHIP_MAP.md) · [变化图与 CCR](Docs/CHANGE_MAP.md) · [完整 2D 版](../BorrowingSun2D/README.md)

## 运行

用 **Godot 4.7.1 .NET** 和 **.NET 8 SDK** 导入 [project.godot](project.godot)，按 **F5**。保留仓库目录结构，3D 工程从同级 `BorrowingSun2D` 编译共享规则。

| 按键 | 操作 |
| --- | --- |
| Enter / Space / 点击按钮 | 在开场开始游戏，或在签收页直接从西岸再玩一次。 |
| W/A/S/D 或方向键 | 在地面、桥和车台上走动。 |
| 1 / 2 / 3 | 选雨 / 选风 / 选晴。 |
| E | 对附近设备施令。塔台用雨升高、用风顺转一档。北庭用风校准采日镜、用晴开放日照。 |
| Shift+E | 选风后逆转塔台一档，或在北庭把采日镜拨回原位。 |
| Q | 在北庭收回局部天气，保留镜面朝向。在别处收回塔台天气，保留水量和塔台朝向。 |
| F | 在塔台设备旁且塔朝西时，切换排水。雨水转入货运配重后，排水口锁定。 |
| G | 站稳在车台中央发车。到站后走到花庭标记，再按一次确认交付。 |
| R | 回西岸重开，复位塔台、镜面、到访记录、果箱、配重和货车。 |

1. 按 `Enter`、`Space` 或点击「开始」。从西岸按 `D` 过低桥上塔。到设备旁按 `1`、`E` 蓄雨，等塔升高 6 m 并锁定。
2. 按 `2`、`E` 转北，桥停稳后按 `W` 走到北庭采日镜。按 `2`、`E` 校准，再按 `3`、`E` 开晴。此时 HUD 显示 `Tower lit`。
3. 按 `S` 沿北桥回塔。按 `2`、`E` 转东，桥停稳后按 `D` 过东桥。两段反射畅通时，HUD 显示 `East lit`，持续受光后水果装车。
4. 沿东岸继续按 `D`，走到车台中央。接光盘保持亮、配重达到 `4.0/4` 时，按 `G` 发车。配重未满或接光盘失光时，HUD 会说明原因。站在车台上等它停靠。
5. 到站后按 `D` 下车走到花庭标记，再按 `G`。签收页显示「水果交付 1/1」。按 `R` 直接从西侧低桥再走一趟。
