# 借晴 · 3D 塔台灰盒

第 05A 轮从 `2d-baseline` 对应的 `6175db9` 开始。先验证塔台从侧视剖面换到三维空间后，玩家仍能从西侧低岸上塔，借雨升高 6 m，再借风接北桥，走到采光庭标记。 [轮次范围与验收](Docs/ROUND_05A.md) · [完整 2D 版](../BorrowingSun2D/README.md)

## 运行

保留仓库目录结构，使 3D 工程能找到同级 `BorrowingSun2D` 的规则源文件。用 **Godot 4.7.1 .NET** 和 **.NET 8 SDK** 导入 [project.godot](project.godot)，按 **F5** 进入主场景。

| 按键 | 操作 |
| --- | --- |
| W/A/S/D 或方向键 | 在地面和桥上走动。 |
| 1 / 2 | 选雨 / 选风。 |
| E | 靠近塔上设备施令。雨用于升塔，风顺转一档。 |
| Shift+E | 选择风后逆转一档。 |
| Q | 收令并停下天气驱动，保留已有水量与朝向。 |
| F | 塔朝入口时切换排水。 |
| R | 回西岸重开，恢复初始塔高、朝向、天气和里程碑。 |

从西侧低岸走过实体低桥，到塔台中央。先按 `1`、`E` 施雨，等平台到高位并锁定。再按 `2`、`E` 施风，等桥接到北岸，步行跨桥到采光庭标记。西岸在 `−X`，北岸在 `−Z`。高位桥必须等转台停稳才可通过。若从北向再顺转，塔仍会进入东向停点，可用 `Shift+E` 回北。

3D 的输入、角色移动、升降与旋转碰撞分别接入 Godot。水量、升降、停靠和北庭里程碑沿用 2D 的 C# 源文件。 [3D 项目配置](BorrowingSun3D.csproj) · [规则复用与验证](Docs/ROUND_05A.md)
