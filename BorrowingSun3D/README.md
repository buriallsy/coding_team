# 借晴 · 3D 塔台灰盒

第 05B 轮接通西岸、北庭和东岸，以及采日镜、塔镜、东岸接光盘的两段反射。3D 分支起于 `2d-baseline`（`6175db9`）。 [本轮设计与验证](Docs/ROUND_05B.md) · [3D 关系图](Docs/RELATIONSHIP_MAP.md) · [完整 2D 版](../BorrowingSun2D/README.md)

## 运行

用 **Godot 4.7.1 .NET** 和 **.NET 8 SDK** 导入 [project.godot](project.godot)，按 **F5**。保留仓库目录结构，3D 工程从同级 `BorrowingSun2D` 编译共享规则。

| 按键 | 操作 |
| --- | --- |
| W/A/S/D 或方向键 | 在地面和桥上走动。 |
| 1 / 2 / 3 | 选雨 / 选风 / 选晴。 |
| E | 对脚下设备施令。塔台用雨升降、用风顺转一档。北庭用风校准采日镜、用晴开放日照。 |
| Shift+E | 选风后逆转塔台一档，或在北庭把采日镜拨回原位。 |
| Q | 在北庭收回局部天气，保留镜面朝向。在别处收回塔台天气，保留水量和塔台朝向。 |
| F | 在塔台设备旁且塔朝西时，切换排水。 |
| R | 回西岸重开，重置塔台、镜面、光路与到访记录。 |

1. 从西岸按 `D` 过低桥上塔。到设备旁按 `1`、`E` 蓄雨，等塔升高 6 m 并锁定。
2. 按 `2`、`E` 转北，桥停稳后按 `W` 走到北庭采日镜。按 `2`、`E` 校准，再按 `3`、`E` 开晴。此时 HUD 显示 `Tower lit`。
3. 按 `S` 沿北桥回塔。按 `2`、`E` 转东，桥停稳后按 `D` 走到东岸标记。两段反射畅通时，接光盘亮起，HUD 显示 `East lit`。

本轮验收终点是走到东岸并点亮接光盘。货运在下一轮接入。 [05A 西岸到北庭记录](Docs/ROUND_05A.md)
