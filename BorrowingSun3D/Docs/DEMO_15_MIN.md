# 《借晴》15 分钟现场演示提纲

AP6412 路线 B。现场从默认开场分别实走 2D 与 3D。用同一种发车反例验证规则一致，再展示代码复用、三维光学改动和复位证据。2D 使用 `2d-baseline`（`6175db9`），3D 使用 05D 候选 `fb4cbb4`。 [课程制作计划](../../BorrowingSun2D/Docs/2D-to-3D/PRODUCTION_PLAN.md#冻结后的比较和交付) · [第 06 轮提交准备](ROUND_06_PREP.md)

## 现场计时

| 时间 | 屏幕与操作 | 讲解交接 |
| --- | --- | --- |
| 00:00–01:00 | 并列两版开场，指出共同目标「把一箱水果送到花庭」。切到 2D 窗口。 | 开场者用一句话交代 Unity L5 是早期设计来源，课程版本先完成并冻结 Godot 2D，再移植至 Godot 3D。介绍 `1/2/3` 选天气、`E` 施令。 |
| 01:00–05:00 | 实走 2D。前两分钟到北庭开晴并回塔，随后转东、登车、演示配重不足拒发，最后交付 `1/1`。保留签收页。 | 操作者报出高位锁、北庭塔镜命中和东岸接光三个检查点。配重不足时直接按 `G`，用等待补满的几秒讲清同一份雨水的去向。 |
| 05:00–09:00 | 实走 3D。沿真实北桥往返，转东观察第二段反射，登车重做拒发并完成签收。两版签收页并列后，分别按 `R` 回西岸，向东走过低桥。 | 操作者指出 2D 的左右移动怎样对应 3D 的方位。对照两版交付分数与重开位置，把全程第二趟留给已有原帧和日志。 |
| 09:00–12:00 | 打开两版类图、共享编译链接和变化表。先追踪一条数据链，再讲五类 CCR。 | 架构讲者解释共用规则与空间接线，指出哪些状态来自真实碰撞和光路。 |
| 12:00–13:30 | 展示两版 Windows 托管开窗截图及日志。每版依次点出开场、首签、`R` 低桥和再签。 | 验证讲者说明自动键盘事件、物理遮挡夹具和实机人工待测范围。 |
| 13:30–15:00 | 切到版本与贡献证据，预留最后约 20 秒总结或接问。 | 各成员在自己的段落说清一项实际贡献和核对方法。收尾者展示已确认的提交或 PR、AI 索引及对应产物。 |

角色由小组按实际贡献分配。彩排时填入每段的讲者与操作员。一个人可兼任操作和讲解，窗口切换由当段操作员统一完成。两位操作员交接时，上一位保留画面并松开按键，下一位先确认焦点。

## 操作员对照卡

| 检查点 | 2D | 3D | 屏幕上要看到 |
| --- | --- | --- | --- |
| 西岸与升塔 | `Enter`，`D` 到塔台设备旁，按 `1`、`E`。 | 同样按键，沿西桥向东。 | 水量到 6、塔升高 6 m 并锁定。站在设备旁再选下一次天气。 |
| 北庭与第一段反射 | `2`、`E` 接北桥，停稳后 `A` 到采日镜旁。按 `2`、`E` 校准，再按 `3`、`E` 开晴。 | 同样施令，沿北桥用 `W` 到镜旁。 | 来光经采日镜到塔镜，东岸接光盘仍暗。 |
| 回塔接东桥 | `D` 回设备旁，按 `2`、`E` 转东，停稳后 `D` 走上车台中央。 | `S` 回设备旁，再按 `2`、`E` 转东，停稳后 `D` 登车。 | 东岸接光盘亮。连续受光后装一箱水果，配重读数上升。 |
| 发车反例和恢复 | 盘亮、有箱且配重低于 `4/4` 时按 `G`。等配重满再按 `G`。 | 同样按键。确认 `East lit`、`Crate 1/1` 和 `Ballast`。 | 首次按键时车留原位。2D 显示「配重还未满」，3D 显示 `Wait for rainwater to fill the ballast.` 满配重、接光仍亮且站稳时，车载着玩家跨谷。 |
| 花庭签收 | 车停后按 `D` 走到旗标，按 `G`。 | 车停后按 `D` 走到花庭标记，按 `G`。 | 两版均显示「水果交付 1/1」。 |
| 复位 | 签收页按 `R`，再按 `D` 实走低桥。 | 同样按键。 | 开场卡片保持关闭，玩家从低岸重开，塔、光、配重、货物和计数复位。 |

转东后直接登车，抵达车面时留意 `4/4`。配重补满前先按 `G`，讲解留到显示拒发后。若到车上时配重已满，继续完成正例，在证据段打开同版的拒发日志，并标注为自动输入复现。 [2D 键位](../../BorrowingSun2D/README.md) · [3D 键位](../README.md) · [2D 发车反例](Evidence/round-05d/2d-headless.log) · [3D 发车反例](Evidence/windows-05d/hosted/3d/route.log)

## 类图与证据讲述

- **09:00–10:00 · 状态从哪来。** 两版协调器把按键、落脚和实际光路结果接入规则。指着类图沿 `ReceiverLit` → `CargoJourney` → `TowerMechanism` 的原水转移 → 场景货车走一遍。说明北庭和东岸到访由 `RouteProgress` 记录，签收由 `CargoJourney` 决定。 [2D 类图](../../BorrowingSun2D/Docs/2D-to-3D/RELATIONSHIP_MAP.svg) · [3D 类图](RELATIONSHIP_MAP.md)
- **10:00–11:00 · 哪些源码复用。** 打开 3D 项目文件，指出同一份 `TowerMechanism`、`RouteProgress` 和 `CargoJourney` 的编译链接。3D 角色、真实桥和车台在场景侧，二维有限线段求交换成三维有限圆面求交，塔镜读取世界姿态。 [3D 编译链接](../BorrowingSun3D.csproj) · [双反射证据](ROUND_05B.md)
- **11:00–12:00 · 为什么是 40%。** 冻结端分母五类。三类直接共享，两类光学实现修改，移除零类，`(2 + 0) / 5 = 40%`。3D 新增独立核心职责为零。输入、表现和引擎适配按各自职责列在变化图中。 [变化图与 CCR](CHANGE_MAP.md) · [复算输出](Evidence/round-05d/ccr.log)
- **12:00–13:30 · 实测到哪一步。** Windows Server 2025 x64 托管无头为 2D 154、3D 160 项，托管开窗为 2D 90、3D 160 项。展示原帧时说明它来自自动输入和 Windows 图形会话。两版原帧均为 1028×578。Windows 实机人工两趟、鼠标与焦点、默认显卡驱动及首次玩家观察继续记为待测。 [Windows 对照表与全部原帧](WINDOWS_ACCEPTANCE.md#托管开窗预验) · [macOS 对照](ROUND_05D.md#实测与签收--2026-11-08)
- **13:30–14:40 · 一条可追溯的 AI 核对。** 预先打开下面的真实交流摘录、首跑日志和复跑结果。讲者指出哪条记录支持两版路线通过，哪条记录只说明截图检查误判，再说明实机签收为何仍是待办。其他成员可用自己的范围、数值或框架贡献讲实际核对。 [现有成员 AI 索引](../../BorrowingSun2D/Docs/AI/djwcb2333/INDEX.md) · [数值核对](../../BorrowingSun2D/Docs/2D-to-3D/NUMERIC_DECISIONS.md) · [整合复测](../../BorrowingSun2D/Docs/Evidence/2026-11-08-round03-integration/RESULTS.md)

Windows 取证讨论摘录。用户要求「开窗跑 2D 基线和 05D 的 3D 候选」，随后指定「暂时没有，先做托管开窗预验」。Codex 复跑后回复「2D 基线通过 90 项，3D 05D 候选通过 160 项，均零失败」，并记录「Windows 实机人工验收仍待完成，`3d-final` 尚未打标」。台上用 2D、3D 各自的 `PASSED` 和 `R` 后第二次签收截图核对这段答复。完整原始交流由成员按课程要求另行提交。 [首跑记录及复跑链接](WINDOWS_ACCEPTANCE.md#托管开窗预验)

若时间允许，用 15 秒点出早期失败的实际影响。第一次内置路线只查 `R` 后初态，独立键码路线发现第二趟低桥无法承托。修复后用相同按键真的走过低桥。这是现场展示 `R` 后还要走桥的依据。 [早期失败、诊断与复验](../../BorrowingSun2D/Docs/TESTING.md#测试过程与证据)

## 彩排与故障切换

1. 用 Godot 4.7.1 .NET 和 .NET 8 SDK 从两个独立检出的项目入口按 `F5`。3D 检出保留同级 `BorrowingSun2D`。演示前两版都停在正常开场，检查投影读得清分数、配重和键位。 [2D 项目](../../BorrowingSun2D/project.godot) · [3D 项目](../project.godot)
2. 事先打开报告 PDF 第 3–7 页，依次备好两版类图、变化图、两版托管原帧和路线日志。每版彩排一次四分钟路线，计时从 `Enter` 到签收。记下实际用时、反例窗口和交接动作。 [报告 PDF](output/pdf/AP6412_Borrowing_Sun_Draft.pdf) · [证据与交付清单](ROUND_06_PREP.md#交付检查表)
3. 误踩边缘时先等安全点恢复。错转塔台时回到设备旁，选 `2` 后用 `Shift+E` 逆转一档。若来光不通，回北庭核对风校准和 `3`、`E`，再转东。若下一分钟要交接且来不及重走，保留现场并切到同一候选的对应原帧，明确标注「此前自动实跑」。 [2D 低桥复位](Evidence/windows-05d/hosted/2d/west-after-r.png) · [3D 低桥复位](Evidence/windows-05d/hosted/3d/west-after-r.png) · [2D 再次签收](Evidence/windows-05d/hosted/2d/cargo-delivered.png) · [3D 再次签收](Evidence/windows-05d/hosted/3d/cargo-delivered.png)
