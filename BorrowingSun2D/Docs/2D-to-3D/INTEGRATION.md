# 框架接入与交接 / Integration

## 当前能做什么

`Framework/BorrowingSun.Domain.csproj` 链接游戏内 `Scripts/Core/*.cs`，不复制规则源码。Godot 工程也编译同一份源码。`Tests/DomainChecks` 是独立控制台验证器，不依赖 Godot 或第三方测试包。

原有生产场景仍使用自己的 TowerMechanism。领域集成夹具证明规则可协作，**不证明新增三岸场景、玩家乘车或完整游戏已完成**。

## 场景接入的唯一状态来源

完整关卡接入时，将 TowerSlice 内部的 `new TowerMechanism()` 改为持有一个 GameSession，并从 `session.Tower` 读取塔。不要让场景另有一个塔、HUD 又读另一份塔。不能同时保留两套水量或完成状态。

正常物理帧顺序：

1. 采集输入并确定唯一交互目标；分派塔、镜面、转水、车辆交互。天气命令需显式分派，禁止把未知命令当风。
2. 调用 `session.Tower.Tick(delta)`，更新塔台位置、对应停点桥口及真实碰撞。
3. 从更新后的几何建立 OpticalSurface 列表，用 Optics2D.Trace 求本帧光路。
4. `session.Resolve(delta, path.ReceiverHit)`，处理局部晴天、接光计时、转水和车程。
5. 用本帧更新后的条件处理转水请求与发车交互，避免沿用上帧命中；必要时将这些交互排队到此阶段。
6. 按 Delivery.Progress 更新实体货车并执行玩家物理移动，再处理到站下车/确认与安全点。
7. View 只读状态，光束使用 solver 返回的光段，不能自行画出一条“成功光线”。

Resolve 不调用 Tower.Tick，避免几何查询使用前一帧塔姿态。TryDepart 在本帧 Resolve 后读取实时条件。原水转移最多进行一次/物理帧。

## 关键 API 和调用约束

| 操作 | 调用者责任 | 规则层保证 |
|---|---|---|
| RequestDock(port, doorwayOccupied) | 目标存在、玩家可交互，提供真实门槛占用 | 合法停点、高位与静止、门槛拒转 |
| Mirror.Cast / Recall | 只在镜面目标执行 | 雨不支持；档位循环；收令保留角度 |
| Trace | 提供当帧有限镜面、法线、接盘、遮挡物，单位统一 | 近交点、正面、严格双镜顺序、有限反射 |
| Receiver.Tick | 由 Session 调用，传实际求解结果 | 连续计时、失光清零、解锁保留 |
| Session.RequestTransfer | 从转水交互入口调用 | 货物、光、停靠与高位前置检查 |
| Tower.TransferToBallast | **仅由 Session 驱动**；不要从 UI 直接调用以绕过光条件 | 等量移水、不超容量、不降低锁定塔高 |
| Session.TryDepart | 本帧 Resolve 后，提供玩家在车内事实 | 检查五项条件与阶段 |
| Delivery.ConfirmDelivery | 真实到站站位和离车状态 | 到站后才能完成，仅计一次 |
| Session.Reset | 场景 R 复位流程调用 | 清空全部领域进度 |

领域公开低层方法便于独立测试，但生产适配层必须使用上面的调用边界。后续若出现另一个生产调用者，再评估更严格的封装，不先增加无用途接口。

## 光学约定

框架使用 System.Numerics.Vector2 与数学坐标（X 向右，Y 向上），不是 Godot.Vector2 像素坐标。场景选择固定比例换算世界坐标；法线同时转换。每个镜面是有限线段，FrontNormal 必须与其垂直。遮挡物在同距命中时优先；最大总程默认 100，反射必须依次命中 SunMirror、TowerMirror，然后 Receiver。

镜面法线 135° 的测试布局：来光沿 +X，到 (2,0) 反向至 +Y，到塔镜 (2,2) 反射至 +X，到 (4,2) 的接盘。它只是几何夹具，不是玩家场景布局。不能用固定的 true 命中结果替代正式场景求解。

## 后续场景任务的明确边界

| 任务 | 完成内容 | 交接证据 |
|---|---|---|
| I01 三岸 | 真实东岸和双侧桥口；显式目标选择；北庭中途标记 | 默认起点实走西→塔→北→塔→东，缺口/门槛/重开反例 |

| I03 运输 | 一箱水果、转水显示、可乘实体车、轨道和交付点 | 正常交付与失光恢复；乘车和重开测试 |
| I04 体验 | 开始/结束页、提示、三分钟熟练路线调优 | 真人试玩观察与实际计时，非夹具数据 |
