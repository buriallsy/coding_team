## 当前操作

| 输入 | Round 03 行为 |
|---|---|
| `A/D` 或方向键 | 行走。 |
| `1/2/3` | 选择雨、风、晴。 |
| `E` / `Shift+E` | 在塔旁用 `E` 施雨，选风时 `E` 顺转、`Shift+E` 逆转一档。北庭选风时 `E` 校准、`Shift+E` 回待机位，选晴时 `E` 施晴。 |
| `Q` | 北庭设备旁收当地天气；其他位置收塔令。保留已有水量和镜面角度。 |
| `F` | 转水前，塔朝入口时开关排水。 |
| `G` | 站上货车后发车，抵达后在花庭旗标确认交付。 |
| `R` | 全局重开并恢复西岸低桥。 |

## 并行框架初值与试玩目标

`djwcb2333` 的 2026-11-07 数值表曾提出 3 秒接光、6 单位配重、手动 `T` 启停转水、12 秒车程、三档镜面以及 `Z/X` 选岸。该分支的光学夹具使用数学坐标与默认 100 总程。原始表继续作为提案和历史证据，现行游戏参数见上方。 [原始数值登记](https://github.com/buriallsy/coding_team/blob/181ec16361f5c22fecd7594519111068cac55baf/BorrowingSun2D/Docs/2D-to-3D/NUMERIC_DECISIONS.md)

原提案的 **180 秒**熟练路线目标分配为说明 15、升塔 35、接北桥 25、调镜送光 45、回塔转东 25、转水登车 20、车程交付 15 秒，150–210 秒为调优参考。Round 04 用真实试玩记录检查节奏。原提案的 3D 行走速度 3 m/s、交互距离 1.5 m 仍属 Round 05 待验证初值。 [当前验收范围](ACCEPTANCE.md)
