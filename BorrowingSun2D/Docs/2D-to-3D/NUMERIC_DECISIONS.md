## 2. 全部玩法参数

| 参数 | 确定值 | 单位 / 精确含义 | 实现与验证边界 |
|---|---:|---|---|
| 完整熟练通关目标 | 180 | 秒（3 分钟） | GameTuning 记录目标；尚无完整玩家实测 |
| 通关时长参考区间 | 150–210 | 秒 | 验收参考，非硬性倒计时 |
| 原水储水容量 | 6 | 水量单位 | TowerMechanism 已实现 |
| 货运配重容量 | 6 | 同一水量单位 | 与原水同一拥有者；等量转移，不生成新水 |
| 塔台最大行程 | 6 | 米，领域高度 | 沿用原规则；场景自行映射空间 |
| 蓄雨速度 | 1.5 | 水量单位/秒 | 沿用原规则；配重非零后禁止补雨 |
| 排水速度 | 1.5 | 水量单位/秒 | 沿用原规则；配重非零后禁止排水下降 |
| 升降速度 | 1.8 | 米/秒 | 沿用原规则 |
| 塔旋转速度 | 45 | 度/秒 | 沿用原规则 |
| 入口 / 北庭 / 东轨目标朝向 | 0 / 90 / 180 | 度 | 显式目标接口已实现；场景选择待接入 |
| 塔停靠容差 | 0.001 | 高度与朝向比较使用的数值阈值 | 原实现复用同一数值；不代表同一物理单位 |
| 满配重判断容差 | 0.001 | 水量单位 | 发车判定 Ballast ≥ 6 − 0.001，即 5.999；容量上限仍为 6 |
| 镜面法线档位 | 90 / 135 / 180 | 度；数学坐标 X 右、Y 上 | 3 档；每次风切换一档，180 后循环回 90 |
| 镜面初始档位 | 0，即 90 | 索引 / 度 | Reset 恢复；Q 只收天气、不重置角度 |
| 相邻镜面档位角差 | 45 | 度 | 180 → 90 为循环归位，不是连续动画时长 |
| 连续有效接光时间 | 3 | 秒 | 失光则未完成计时清零；解锁后保留到 R |
| 原水转配重速度 | 1 | 水量单位/秒 | 必须手动启动；失光暂停，条件恢复继续 |
| 全量转水时长 | 6 | 秒，6 ÷ 1 | 条件持续有效时的推导值，不含交互、暂停和登车 |
| 货车行程 | 12 | 秒 | 发车后不再依赖光；场景轨道长度不改变该时间 |
| 货车进度范围 | 0–1 | 归一化进度 | min(1, 已行驶秒数/12)；不是米 |
| 货车阶段数 | 4 | Waiting、Travelling、Arrived、Delivered | 到站不自动通关，需下车确认 |
| 交付计数 | 0 或 1 | 箱 | 重复交付不增加；R 清零 |
| 必需光学顺序 | 2 次反射、3 个依次命中阶段 | 采日镜 → 塔镜 → 接光目标 | 不可跳过或交换；不把角度正确当作实际接光 |
| 光线最大总程 | 默认 100 | 统一玩法单位 | 两次反射共享总长度预算，不是每段各 100 |
| 光学几何容差 | 0.0001 | 求交算法数值阈值 | 有限线段、近交点、正面入射；共面遮挡物优先 |
| 镜面法线垂直校验容差 | 0.001 | 归一化切向与法线点积的绝对值上限，无量纲 | Optics2D 输入有效性检查；不同于光学求交容差 |
| 帧时间有效范围 | 有限且 ≥ 0 | 秒 | 拒绝负值、NaN 和无穷；不是固定帧率要求 |
| 2D 行走速度 | 218 | px/s | 沿用 SlicePlayer；不直接迁移为 3D 米制速度 |
| 2D 重力 | 1120 | px/s² | 沿用 SlicePlayer |
| 2D 最大下落速度 | 640 | px/s | 沿用 SlicePlayer 的下落速度限幅 |
| 2D 脚部偏移 | 17 | px | 沿用 SlicePlayer 的脚点/复位坐标约定 |
| 2D 当前交互距离 | 82 | px | 沿用现有塔交互；新增设备目标选择待接入 |
| 当前输入 deadzone | 0.2 | 无量纲 | project.godot 已有输入动作配置；不是按键延迟 |
| 3D 初始行走速度 | 3 | m/s | 未来适配初值，尚未实现或实测 |
| 3D 初始交互距离 | 1.5 | m | 未来适配初值，尚未实现或实测 |
| 虚拟分辨率 | 1280 × 720 | px；16:9 | 当前项目；canvas_items 拉伸，保持比例 |

注意：归一化向量点积容差、位置距离和角度虽然都用浮点数表示，不能混为同一种物理单位。2D 像素、领域米制高度及光学玩法单位必须在场景适配处统一转换。未指定新关卡每段桥长、镜面坐标或 3D 几何尺寸；这些由场景集成验证确定，不伪造为本轮已定数值。

## 4. 操作和零值复位

| 项目 | 明确决定 | 接入状态 |
|---|---|---|
| 数字键 1 / 2 / 3 | 雨 / 风 / 晴 | 1、2 已接；3 待场景接入 |
| 2D / 3D 移动 | A/D 或左右箭头 / WASD | 2D 已有；3D 待实现 |
| E / Q | 当前目标施令或情境交互 / 只收当前目标天气 | 新设备与货车交互待接 |

| 当前高亮目标 | 同时最多 1 个 | 优先行驶车辆约束，再到站交付点，再最近设备；等距按稳定节点 ID |
| 全局复位 | 水、配重、高度、塔朝向、受光计时、行车计时、交付计数归 0；镜面索引归 0（90°） | GameSession.Reset 已实现；场景还须复位位置与安全点 |
| 失足 / 落水 | 保留机关进度；回有效安全点 | 运输时回车内；不清零原水或复制货物 |
