# 借晴｜游戏构思

玩家来到一座停运的山谷货站，要把一箱水果送往谷对面。中央塔先靠雨水抬高，再借风换接两岸。玩家把向阳山的日光经塔镜送到山阴村，升塔存下的同一份水随后流入货运配重，带动货车跨谷。游戏的核心是观察天气如何改变装置，并把上一步留下的结果用到下一步。

## 从天井跨谷到侧视剖面

既有 Unity L5《天井跨谷》先于这次课程移植，提供了中央塔、三岸停靠、双镜接光和跨谷交付的设计参考。课程原型把这一段收束成一个可连续游玩的短关卡，先做完整 Godot 2D，再用同一套玩法做对应的 Godot 3D。

侧视剖面把低位入口和高位采光庭放在塔的左侧，右侧留给山阴村与货轨。玩家在同一屏里能对照水箱、台面、桥口和两岸的高差。升高只改变塔台能到的层，风再改变桥通向哪一岸。塔台始终提供水平站立面，桥舌收放与接缝表现转台换向。短关卡从低岸上塔开始，把注意力集中在同一台装置的几次用途变化。

## 当前能玩到哪里

第 02 轮从西侧低岸起步。玩家走上活动塔台，施雨升高，再施风接通北侧采光庭。到北庭调准采日镜并施晴，返回塔上转向东岸后可以用真实反射点亮接光盘。北庭与东岸旗标记录步行到访。转水和交付属于下一轮。 [当前版本与试玩入口](CURRENT_STATUS.md)

## 完整关卡的共同玩法

1. **蓄雨升塔。** 水箱上涨，玩家随活动塔台升高。高位机械锁扣合后，可以停雨并保留已存的水和高位。
2. **借风接桥。** 玩家将塔换接到北侧采光庭，走过实际接通的桥，在采日镜旁用风调整镜面。
3. **借晴送光。** 采日镜在晴天接住世界太阳，先把光反射到塔镜。玩家回到塔上并转向东侧货轨，塔镜才把第二段光送到山阴村的接光盘。朝向和遮挡都能改变实际光路。
4. **用原水交付。** 村庄持续得光后，一箱水果出现在货车上。塔台已锁定，同一份雨水可以转入货运配重。接轨、受光和配重条件满足后，玩家搭车跨谷，到站下车确认交付。

两版共用停靠、接光、转水、发车、交付与恢复条件。2D 用侧视中的桥接缝、有限镜面线段和可见光段表达这些规则。3D 让圆台真实换向，桥口和镜面在三维空间中对齐，玩家从固定观察方向辨认装置。两版可以各自调整镜头、构图与交互距离，玩家做出的判断和有效解法保持对应。 [制作顺序和验收](PRODUCTION_PLAN.md)

## 等试玩回答的问题

- 玩家能否从水箱和台面看出雨在改变高度，并在桥仍有缺口时判断下一步是用风接岸？
- 玩家能否区分「光已经到塔镜」和「光已经到村庄」，再从塔镜朝向推断如何接通第二段？
- 玩家能否看出配重增加的是原先升塔用的水，并在断光后知道怎样恢复发车条件？
