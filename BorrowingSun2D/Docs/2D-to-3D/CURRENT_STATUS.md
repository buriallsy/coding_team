# 借晴 2D 到 3D 当前状态

当前是 **Godot C# 第 04 轮 2D 验收候选**。西岸上塔，借雨升高，接北桥调镜施晴，回塔转东借光，登车跨谷并交付一箱水果。 [运行说明](../../README.md) · [第 04 轮记录](ROUND_04.md)

## 试玩路线

1. 用 Godot 4.7.1 .NET 和 .NET 8 SDK 打开 [project.godot](../../project.godot)，按 F5 运行。在开场按 Enter 或点击开始。
2. 按 `D` 或 `→` 向右走过低桥，到塔上设备旁。按 `1` 选雨、`E` 施令。水满 6 单位时，平台升高 6 m，机械锁扣合。
3. 按 `2`、`E` 接北桥，向左走到采日镜。选风按 `E` 调镜，再按 `3`、`E` 开当地日照。
4. 向右沿北桥回塔上设备旁，按 `2`、`E` 转东。保持东盘受光，沿东桥走上货车，等一箱水果装车且配重满 `4/4`，按 `G` 发车。
5. 车停稳后向右走到交付旗标，按 `G` 签收，结束页显示 `1/1`。`R` 回到西岸低桥。
