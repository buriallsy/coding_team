# 借晴 2D 到 3D 当前状态

当前是可运行的 **Godot C# 内部 MVP**。已走通「西侧低岸 → 上塔 → 雨升高位 → 风接北桥 → 步行到采光庭」。北侧采光庭的旗标是本版终点，抵达后画面显示「已抵达采光庭」。[运行说明](../../README.md) · [Figma 灰盒过程板](https://www.figma.com/design/UINwS4sIWy2BFhFRFcJ0pB/ntu?node-id=471-55)

## 试玩路线

1. 用 Godot 4.7.1 .NET 和 .NET 8 SDK 打开 [project.godot](../../project.godot)，按 F5 运行。
2. 按 `D` 或 `→` 向右走过低桥，到塔上设备旁。按 `1` 选雨、`E` 施令。水满 6 单位时，平台升高 6 m，机械锁扣合。
3. 按 `2` 选风、`E` 施令，等北桥停稳接通。按 `A` 或 `←` 向左过桥，走到旗标。可用 `Q` 收令、塔朝入口时用 `F` 开关排水、用 `R` 重开。
