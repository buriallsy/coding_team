# 借晴 2D 到 3D 当前状态

当前是 **Godot C# 第 02 轮灰盒**。路线为「西岸上塔 → 雨升 → 风接北庭 → 调镜施晴 → 回塔转东 → 接光盘受光」。北庭和东岸旗标仍记录实际步行到访。 [运行说明](../../README.md) · [第 02 轮记录](ROUND_02.md)

## 试玩路线

1. 用 Godot 4.7.1 .NET 和 .NET 8 SDK 打开 [project.godot](../../project.godot)，按 F5 运行。
2. 按 `D` 或 `→` 向右走过低桥，到塔上设备旁。按 `1` 选雨、`E` 施令。水满 6 单位时，平台升高 6 m，机械锁扣合。
3. 按 `2`、`E` 接北桥，向左走到采日镜。选风按 `E` 调镜，再按 `3`、`E` 开当地日照。
4. 向右沿北桥回塔上设备旁，按 `2`、`E` 转东。观察塔镜反射抵达东岸接光盘。`R` 重开并恢复西岸低桥。

## 已验证

光路专项从默认入口验证采日镜、塔镜和东盘，另用实际碰撞体核对遮挡。三岸路线保留 `R` 后实走低桥的回归。 [第 02 轮验收](ROUND_02.md) · [第 01 轮验收](ROUND_01.md) · [第 00 轮复位诊断](../TESTING.md)
