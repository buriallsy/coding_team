# 借晴 2D 到 3D 当前状态

当前是可运行的 **Godot C# 第 01 轮灰盒**。路线为「西侧低岸 → 上塔 → 雨升高位 → 风接北桥 → 步行到采光庭 → 回塔 → 风接东桥 → 步行到东岸」。北庭旗标记录中途进度，走到东岸旗标后完成本轮。 [运行说明](../../README.md) · [第 01 轮记录](ROUND_01.md)

## 试玩路线

1. 用 Godot 4.7.1 .NET 和 .NET 8 SDK 打开 [project.godot](../../project.godot)，按 F5 运行。
2. 按 `D` 或 `→` 向右走过低桥，到塔上设备旁。按 `1` 选雨、`E` 施令。水满 6 单位时，平台升高 6 m，机械锁扣合。
3. 按 `2` 选风、`E` 施令，等北桥停稳接通。按 `A` 或 `←` 向左过桥，走到北庭旗标。
4. 向右沿北桥走回塔上设备旁，再按一次 `E`。等东桥接通，向右走到东岸旗标。`Shift+E` 逆转一档，`Q` 收令，塔朝西时用 `F` 开关排水，`R` 重开。

## 已验证

复测覆盖实体三岸路线、两侧门槛拒转、反向回北庭和 `R` 后实走低桥。第 00 轮曾出现复位后低桥画面与碰撞不同步，本轮保留实走用例，并检查东桥碰撞随复位关闭。 [第 01 轮验收](ROUND_01.md) · [第 00 轮诊断](../TESTING.md)
