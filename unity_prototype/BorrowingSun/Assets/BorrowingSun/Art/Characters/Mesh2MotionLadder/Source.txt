This is the original hand-keyed in-place vertical ladder action, not a generated substitute.
Local conversion extracts Climb Ladder only (frames 1–87 at 24 fps, about 3.583 s);
retains the original rest skeleton, bone rotations and timing; exports armature FBX.
The FBX static hierarchy is neutral T pose, with the original action baked separately.
Unity still exposes the first animated pose for an armature-only animated FBX;
therefore an additional no-animation Mesh2Motion_LadderRest.fbx supplies the
original neutral calibration transforms. Bone names match; only the file-derived
root name is remapped. Unity verifies matching bones and straight horizontal arms
before building Humanoid. The original action frames 1–87 are unchanged.
Unity explicit Humanoid mapping retargets to the existing Kenney player Avatar.
The original shared ground controller is unchanged. Journey owns physical motion;
optional Playables presentation advances from signed actual ladder displacement,
pauses when W/S is released, and runs backwards while descending.
L5 pacing: one loop represents two 0.4 m rungs (0.8 m travelled).
This is a whitebox pacing calibration, not a claim of exact contact IK.
